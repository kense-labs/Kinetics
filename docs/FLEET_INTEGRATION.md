# 工业舰队集成技术文档

## 1. 机型接入要点

### UR5e（Universal Robots 协作臂，Menagerie 官方模型）

- **末端嫁接**：UR5e 出厂裸腕，把 Panda 平行夹爪按官方 `attachment_site`
  （wrist_3_link 局部 `(0, 0.1, 0)` + 工具系四元数）嫁接上去；夹爪的腱传动/
  等式/执行器/网格全部以 `ph_` 前缀重命名注入，与宿主零撞名。
- **台座安装**：基座抬到桌沿 25cm 台座柱上 `(0.05, 0, 0.25)`。网格扫描
  （高度×水平偏移×姿态）证明只有这个区间能让全部任务位姿既收敛又无桌面接触——
  原装肘上 home 会把前臂扫进桌面。
- **接触排除**：嫁接手掌与腕鼓有接触排除对；前臂/上臂列入 forbidden_bodies。
- **能力边界**：近侧黄盘（sort 托盘2）只有前臂贴桌面的姿态能到——IK 否决器
  拒绝这类解，所以 UR5e 不下发 sort。这不是缺陷，是真实安装几何。

### xArm7（UFACTORY，Menagerie 官方模型）

- **末端换装**：拆下原装夹爪子树（连同其腱/等式/接触排除/执行器），在
  `link_tcp` 法兰装真空吸盘工具（法兰座+双节波纹管+橡胶吸盘）。
- **真空吸附语义**：吸盘贴近工件顶面（间隙 ≤4mm 且 XY 对中 ≤3cm）+ 真空开 →
  运动学挂载（与无人机吊挂同一约定）；真空关 → 释放。负载重量不回传臂部
  （文档化简化）。吸盘几何带 2mm margin——平贴零穿透时 MuJoCo 不产生接触对，
  纯接触检测永远等不到吸附（实测踩坑）。
- **能力边界**：吸盘只能干顶面吸附的活，故只下发 depalletize。

### Kinova Gen3（Menagerie 官方模型）

- **连续关节陷阱**：Gen3 的 1/3/5/7 扭转关节在 MJCF 里**不带 range**（无限位），
  IK 裁剪若只看 jnt_range 会把这四个关节冻死在 [0,0]——全域不可达。
  修复：按 `jnt_limited` 放行。
- **末端嫁接**：Panda 夹爪挂在 bracelet_link 的 `pinch_site`。
- **能力边界**：平垫夹爪夹圆柱毛坯在搬运摆动中会滚脱（真实车间用 V 型块
  夹爪）。tending 不下发给 Gen3——能力边界按实测划定，不假装全能。

## 2. 共享机制（物理/规划层）

| 机制 | 说明 |
| --- | --- |
| 多对象泛化 | `targets`/`sources`/`placed` 按对象索引；`active_index` 取最高未归位件（拆垛自然从上到下），**抓取期间锁定**（锁不住会中途换目标把整个场景打散——实测） |
| 碰撞感知 IK | 多重启动 + 每机型 `ik_pose_ok` 否决（自碰撞、贴桌面、近端连杆碰工件） |
| 任务级节奏 | `time_scale`（插装 1.8×：软腕瞬态收敛）/ `travel_z`（物流任务更高的搬运高度）/ `max_cycles`（多物体任务预算） |
| 抓取高度语义 | `grasp_above`：夹爪包心（0.001）/ 吸盘顶面（0.039）/ 小件抬高（0.012） |
| 预演安全 | 吸盘挂载恒成立→跳过下落检查；支撑面上的接触丢失=正常放置而非丢抓 |

## 3. 踩坑全记录（都带回归测试）

1. 夹爪嫁接不穿模挂载点 = 官方 attachment_site/pinch_site；装在腕鼓中心会严重穿模
2. 腕部伺服 28Nm 饱和 + 0.3 rad 下塌 → 接触排除对缺失（手掌碰撞网格与腕鼓互撞）
3. UR5e 台座高度扫描：只有 (0.25, x=0.05) 全域可达且零接触
4. Gen3 连续关节被 IK 裁剪冻结（range [0,0] 语义是"无限位"不是"锁死"）
5. 吸盘平贴零穿透不产生接触对 → 改近距判定（真空密封本来就是贴附即吸）
6. 多对象任务 active 切换在抓取中途换目标 → 打散场景 → 抓取期锁定
7. 拆垛/摆盘搬运高度要高于已码好的箱子（运输摆动穿透会撞飞它们）
8. Panda 夹爪 8.6cm 行程夹不了 8cm 纸箱（单边触爪）→ 摆盘件 4cm
9. 圆柱毛坯在平垫夹爪里摇摆滚脱 → tending 排除 Gen3（真实车间用 V 型块）
10. 任务周期预算：4 件摆盘在 1.2× 节奏下要 ~51 周期，默认 30 不够 → 按任务下发

## 3.5 工业动作链与输送带(P0/P1 已补)

- **输送带真实运转**：运动学带驱动(带速 0.15m/s)+尾端挡停+队列限距(按件宽)+
  取料区到位停线。拆垛的纸箱放上皮带随带运走；摆盘的送料器把件顶到挡停排队。
- **机床 I/O 动作链**(tending v2)：滑门随机器人到位自动开关(持件目标为卡盘时提前开,
  否则臂速快过门速会刮门——实测)；磁力卡盘夹持保持(未被抓取的件钉在盘面上,防抓偏带倒);
  加工节拍 2.5s;状态旗起落(红→绿);完工自动改目标到成品盒触发卸料段。两件全程自动。
- **节拍报告**:`session.export()["cycle_time"]` 输出总仿真秒数、逐阶段耗时分解、
  逐件完工时刻——可直接用于产能估算。

## 4. v3 机型外观精调

- **差距根因**：Panda/OpenArm 的官方资产自带多层配色（米白机身/软黑关节/
  金属银 reflectance）；UR5e/xArm7/Gen3 是 Menagerie 素灰材质 + 单灯或无灯
  （Gen3 甚至未定义任何材质），在同渲染管线下自然显素。
- **精调手法**（不动网格，只调材质与布光）：
  - UR5e：UR 蓝加深至真机色 `0.30 0.55 0.76`；连杆缎面铝（specular/reflectance），
    关节深灰金属；拆除原装窄聚光灯（只照腕部、全场变暗），换三点布光。
  - xArm7：纯白→哑光柔白（纯白高光溢出）；法兰金属银 reflectance 0.7；
    腕部加 UFACTOR 红环（视觉专用 geom，零碰撞零质量）。
  - Gen3：新增全套材质——炭黑/石墨分层机身 + 银色腕球（金属反射）+
    腕带 Kinova 绿 LED 环（emission 自发光）；删除 visual 默认类的 rgba
    （否则它压过材质色——MuJoCo 里 geom rgba 优先于 material rgba）。
  - 三台统一三点布光：主光 trackcom (0.7,-0.9,2.3) + 无阴影补光 (-0.9,0.8,1.5)。
    阴影出来了，金属高光出来了，配色层次出来了。
- 验证：`renders/material_{before,after}_*.png` 同机位对照。

## 5. v3 独占新工艺（无抓取轨迹引擎 + 码垛逆流程）

- **驻留引擎 `_trace_tick`（weld/glue 共用）**：工装标记是钉死在原位的自由体
  （每 tick 复位 qpos/qvel，触碰不移位——工装语义）；TCP 对 active 标记带
  工艺间隙驻留满节拍即完工（标记变绿），按序推进。`placed[]` 由钩子按
  驻留状态覆写（与 depalletize 闩锁同模式），通用稳定计时驱动 success。
  规划层新增 `touch`（驻留作业）阶段；`eligible_phases` 对轨迹任务只读观测
  字典（`task_id`/`placed`），不碰仿真器真值——视觉策略同享此路径
  （`test_all_stage_and_target_planning_uses_supplied_estimates` 守卫）。
- **码垛下线（palletize）**：拆垛逆流程。纸箱在带上游排队，`_drift_on_belt`
  向尾端挡停积攒（取件区到位停线）；吸盘按先左、后右、再叠顶码上托盘，
  码稳（到位+低速+松手）闩锁完工。
- **任务矩阵差异化**：每台机型招牌工序独占（见 README 矩阵），
  基础工况只保留至多一个对照项；`/api/config` 按 `spec.tasks` 过滤下发。

## 6. 已知边界

- 每机型任务清单按实测划定（见 README 矩阵），跨机型点任务会得到明确报错
- 新任务（tending/depalletize/kitting/weld/glue/palletize）仅 privileged 观测模式
- 前端需 `npm run build`（上游惯例）；换机型需重启服务（环境变量在启动时读取）
- 吸盘负载不回传臂部力矩（运动学挂载简化）；拆垛/摆盘不支持位置扰动评估
- 焊接/涂胶的驻留在指尖平面上方 2mm 工艺间隙完成（非接触式工艺语义），
  不模拟热传导/胶体挤出
